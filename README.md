# TikTok Conveyor

Массовая загрузка видео в TikTok. Берёт длинное демо-видео, нарезает на сотни коротких клипов, генерирует уникальные тексты через DeepSeek, накладывает их на видео и публикует через несколько аккаунтов.

## Как это работает

```
1 длинное видео (10 мин)
↓ FFmpeg random cut
100+ клипов по 15-30 сек
↓
DeepSeek генерирует уникальные тексты + хэштеги
↓
FFmpeg накладывает текст на каждый клип
↓
Playwright логинится в аккаунты и публикует
↓
TikTok сам подбирает музыку
```

## Быстрый старт

```bash
# 1. Установка зависимостей
pip install -r requirements.txt
playwright install chromium

# 2. Установи FFmpeg
#   Windows: winget install ffmpeg  (или скачай с ffmpeg.org)
#   macOS:   brew install ffmpeg
#   Linux:   sudo apt install ffmpeg

# 3. Положи демо-видео
#   cp your_video.mp4 input/demo.mp4

# 4. Создай accounts.txt
#   логин1
#   пароль1
#   логин2
#   пароль2

# 5. Задай API ключ DeepSeek
#   export DEEPSEEK_API_KEY="sk-xxxxx"

# 6. Запусти
python main.py --mode full --prompt "описание продукта"
```

## Режимы работы

| Команда | Что делает |
|---------|-----------|
| `--mode clips` | Только нарезка видео |
| `--mode texts` | Только генерация текстов |
| `--mode finalize` | Наложение текста на клипы |
| `--mode login` | Только логин в аккаунты |
| `--mode upload` | Только загрузка видео |
| `--mode full` | Полный конвейер |

## Параметры

- `--input` — путь к исходному видео (по умолч. input/demo.mp4)
- `--clips` — сколько клипов нарезать (по умолч. 100)
- `--prompt` — описание продукта для генерации текстов
- `--min-delay` — мин. пауза между загрузками в минутах (30)
- `--max-delay` — макс. пауза между загрузками в минутах (120)

## Структура проекта

```
tiktok-conveyor/
├── main.py                  # Оркестратор
├── video_processor.py       # Нарезка видео через FFmpeg
├── text_engine.py           # Генерация текстов через DeepSeek
├── video_finalizer.py       # Наложение текста на видео
├── account_manager.py       # Логин и сохранение сессий
├── uploader.py              # Загрузка на TikTok
├── requirements.txt
├── accounts.txt             # Логин
Пароль
... (создаётся тобой)
├── input/                   # Сюда кладёшь видео
├── output/clips/            # Нарезанные клипы
├── output/final/            # Готовые к загрузке видео
├── sessions/                # Сохранённые сессии
└── output/texts.txt         # Сгенерированные тексты
```

## Принцип работы с сессиями

1. При первом запуске `--mode login` открывается браузер
2. Ты вручную вводишь капчу/код, если нужно
3. Куки сохраняются в `sessions/`
4. При последующих запусках куки подгружаются — загрузка автоматическая
5. Когда сессии протухают (1-2 недели) — повторяешь `--mode login`
